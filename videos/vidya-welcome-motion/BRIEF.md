# Vidya welcome motion

- workflow: motion-graphics
- flow: autonomous
- Deliverable: a new original six-second silent welcome graphic for the balanced Vidya visitor landing.
- Canvas: 720 x 360, 30 fps, MP4 with a static SVG fallback.
- Direction: curiosity, reading and investigation, then making. Restrained paper, navy, violet and mint. No old intro, mascot celebration, stock assets or claims about learning outcomes.
- App playback: optional play action with native controls. No autoplay, looping background or forced introduction. Reduced motion and failed loading use the static fallback. Accessible introductory copy lives in HTML outside the video.
- Authorization: the user asked to implement this motion graphic in the application and has authorized direct production delivery. Rendering the small application asset is part of that existing authorization. No purchase or separate distribution is requested.
- Review: automated composition checks, explicit proof snapshots and rendered media metadata. This does not establish learning or retention effectiveness.
- Assets: original authored SVG learning objects only; no external sourcing required.
- Palette: paper #f7f8fc, ink #202c46, violet #6254b4, mint #dceee5, white #ffffff and muted #5e6b80.
- Localization: no English text baked into the graphic. The same learning-object diagram accompanies independently authored English and Hindi page copy.
- Output paths: `public/learning/vidya-welcome.mp4` and `public/learning/vidya-welcome.svg`.
