# Vidya Quest

A cosmic learning adventure for Grade 5 scholars. Built with Next.js 15, Tailwind, Framer Motion, Tone.js, and Web Speech API.

## Features

- Cambridge Primary Stage 5 aligned: Maths, Science, English
- Hindi, Marathi, GK (India + Pune + space + world geography)
- 200+ questions across 30+ topics
- XP, levels, streaks, coins, badges, daily quests, power-ups
- Procedural background music (Tone.js)
- Miss Vidya voice teacher (Web Speech API)
- Glassmorphic Cosmic Academy design
- Full progress tracking and parent dashboard
- localStorage persistence

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Optimised for Vercel. Push to a Git repo, connect on Vercel, deploy.
