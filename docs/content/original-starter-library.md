# Original starter library review packet

24 distinct short fictional titles were AI-authored as drafts and passed a bounded implementation-agent editorial release review, with six at each of four reading levels. Each JSON contains paired English/Hindi paragraphs and an original geometric SVG cover. Text complexity levels do not establish age, reading ability or curriculum stage. Nothing is an independently validated learning-outcome claim.

Authors: AI-authored for Vidya during implementation. No third-party story text or illustrations copied. No legal rights opinion is claimed. Rights/provenance are recorded individually in each JSON. The initial authored state was draft. On 2026-10-08 the root implementation agent read all24 English/Hindi texts and accepted all24 covers in a static contact sheet. The representative red-cup desktop reader was browser-accepted for loading/art, page2, pages/scroll, 21px font, Hindi, night theme, bookmark and position after exit/reload. Each title records the actual checks and limitations. Root authorized bounded publication after all24 contract/assets checks passed. Phone/tablet, screen-reader, physical-device narration, independent expert and child usability acceptance remain pending.

## Publication checklist for every title

- Read English and Hindi paragraphs together; correct translation and factual claims.
- Check developmental suitability and record eligible placements separately from reading level. Preschool sees only explicit `earlyYearsEligible: true` entries.
- Confirm activities described are fictional, do not give unsafe instructions, and adult supervision is mentioned where relevant.
- Check non-coercive relationships, choice, privacy and respectful language. No perfect-AI or educational outcome promises.
- Validate paragraph alignment, unique identity, loading, read-aloud fallback, keyboard/buttons, static illustration and asset provenance.
- Record actual reviewer, date, performed checks and limitations in the JSON review record. Independent educator, developmental expert and Hindi linguist review remains unclaimed.
- Set that JSON and its metadata entry to published only after checks pass; unfinished reviews stay draft.

## Reader compatibility

Legacy Gutenberg IDs, full licenses, source links and historical chapter/scroll progress remain. Paragraph index/offset fields are additive. Paginated mode shows one paragraph at a time with Previous/Next, keyboard arrows and a touch alternative. Scroll mode uses the same paragraphs. Layout, font, theme and language use the stable paragraph anchor; old positions retain the legacy scroll fallback. Explicit bookmark saves the current place, while automatic saves continue.

The initial library filter opens readable in-app content. Catalog-only entries remain labelled and cannot claim a completion action. Read-aloud follows central mute/narration/volume controls and stops when the page is hidden. Production and physical-device speech acceptance remain to be performed. The desktop representative reader acceptance does not establish every-title browser or mobile acceptance.
