# Balanced welcome and parent contrast, 7 October 2026

Observed defect: the production Nursery parent guidance uses a shared white learning-panel while its text inherits near-white parent text. This makes the panel unreadable. Parent report surfaces now have explicit, scoped dark tokens, including guidance, evidence, placement editing and native controls. Child enrollment retains its light surface.

The owner asked for a more balanced child frontend and a fresh introduction to Vidya. The previous companion-first introduction is not reused. Visitor entry now explains the existing books, stories, practice and creation offering, links directly to the public mission, and keeps account device-code entry and parent onboarding alongside it. Returning learners open learning immediately, with an optional What is Vidya disclosure.

Palette: paper #f7f8fc, white #ffffff, ink #202c46, muted #5e6b80, violet #6254b4, mint #dceee5. Outfit is the heading role; Plus Jakarta Sans is the body/control role, with Noto Sans Devanagari for Hindi. The signature is an original curiosity-to-creation diagram, rather than a large mascot or decorative 3D object.

On phones the introduction precedes the code form. No animated opening blocks access. Returning preschool and school home surfaces use white activity panels, restrained colored artwork, smaller corner radii and direct learning choices. Preschool keeps concrete pictures, read-aloud, large targets and its exact placement content. Two-column activity cards become single-column cards on phones to keep titles readable.

Anekantavada perspectives: visitors need to understand the purpose; children need a direct next step and concrete choices; parents need reliable readable controls and progress evidence; teachers need honest coverage labels; accessibility needs static alternatives and clear focus; English/Hindi inclusion needs equivalent HTML descriptions; engineering needs existing account linking and progress to remain unchanged. Conflicting priorities are resolved by separating optional explanation from the learning action. These decisions are not established child preferences or retention results.

A new original silent six-second HyperFrames asset is optional. HTML carries the translated message. The static illustration remains available when motion is disabled, reduced motion is preferred, or video fails. Playback requires a click, has native pause controls, and never loops.

No schema migration, account reset, content deletion, analytics expansion or OAuth configuration change is included. The offline public cache advances normally without raising the existing account compatibility floor. Validation and release evidence are recorded separately in the pull request. Physical device, child usability and learning/retention evidence remain pending.
