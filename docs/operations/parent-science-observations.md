# Parent Science preparation observations

The parent Overview receives a server-minimized projection of the current Science Term 1 revision record. It reports saved nonblank practice answers, saved mock answers, self-marked mock questions, submission state and learner-assigned marks. Unit breakdowns use the fixed current paper identities; extra identities are not counted.

No typed answer, free text, hint transcript, click history or inferred personality/ability score is returned. The parent guide continues to provide authored model answers separately. The learner can read what is shared through an explicit disclosure in the revision view.

Submission does not imply all questions were answered. Marks describe the questions self-marked so far and remain explicitly self-assessed after guide viewing; they can change after edits. No revision lesson-completion record existed, so historical completion is not reconstructed from a cursor, page visit, navigation index or parental statement. Oral practice, paper work and learning away from Vidya may be absent.

The report labels cloud versus local evidence and uses the server sync timestamp. Parents can refresh immediately; the existing foreground/30-second refresh also updates reports. Previously validated reports remain mounted while background requests run, preserving open editor state. Authorization denials still remove access. Hidden-tab cache clearing and shared-family boundaries remain in force.

This release reuses current learner state and parent permissions, introduces no database migration or new analytics, and does not write or reset any learner's existing progress. Existing revision question IDs and mock ordering are unchanged.
